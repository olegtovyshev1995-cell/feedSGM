# Шаблоны листов Google-таблицы

Каждая площадка читает данные со своего листа. Импортируйте нужный шаблон
в вашу Google-таблицу (`Файл → Импорт → Загрузка → Вставить новые листы`)
и назовите лист **ровно так, как ждёт конфиг** (`config/config.example.yaml`).

| Файл шаблона | Имя листа в конфиге | Площадка |
|---|---|---|
| `avito_autozagruzka_шаблон.xlsx` | `Автозагрузка_авто` | Avito (автозагрузка) |
| `autoru_легковые_шаблон.xlsx` | `Фид (легковые)` | Auto.ru (легковые) |
| `drom_легковые_шаблон.xlsx` | `Drom_легковые` | Drom (легковые) |

## Как заполнять

- **Одна строка = один автомобиль.**
- Красные заголовки — обязательные поля (без них сборка фида упадёт с
  указанием номера строки). Зелёные — необязательные.
- Наведите курсор на заголовок — во всплывающем комментарии пояснение.
- `Id` / `unique_id` / `idOffer` — уникальный и **постоянный** идентификатор.
  Не меняйте его между выгрузками, иначе площадка создаст дубль.
- Цена, объём, мощность, пробег — только числа, без пробелов и валюты.
- Фото: Avito — через запятую; Auto.ru и Drom — через `|`.

## Важно про шапку Avito и Auto.ru

В шаблонах Avito и Auto.ru первые строки — служебные (описание,
обязательность, формат, строка-пример). Не удаляйте и не переставляйте их:
конфиг знает, с какой строки начинаются заголовки (`header_row`) и данные
(`data_start_row`). Для Drom всё проще — заголовки в строке 1, данные со
строки 2.
