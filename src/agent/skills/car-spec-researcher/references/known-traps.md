# Известные ловушки и искажения

Проверяй каждую перед выдачей файла. Это список того, на чём спецификации ломаются чаще всего.

## Мощность и момент

| Ловушка | Как проявляется | Что делать |
|---|---|---|
| SAE hp vs PS/DIN vs кВт | Одна машина: 405 hp (США) / 397 PS (ROW) / 292 кВт. Агрегаторы пишут «292 hp», путая кВт | Всегда указывать стандарт; кВт × 1,36 = л.с.; если цифра не сходится с этой формулой — источник перепутал единицы |
| Мощность по ГОСТ в ПТС РФ | В ПТС может стоять другая цифра, чем на сайте (например, из-за замера или дефорсирования) | В блоке 13 всегда: «л.с. сверить с ПТС/СБКТС» |
| lb-ft вместо Нм | «430» без единицы — это lb-ft (=583 Нм), а не Нм | Конвертировать скриптом, оригинал сохранять в скобках |
| Обороты момента различаются по рынкам | 583 Нм при 3500 (ROW) и при 4500 (US) — обе цифры верны | Не «усреднять», писать по версии |
| «Суммарная мощность» гибридов | Китайские сайты пишут 综合功率 (системная), европейские — мощность ДВС и электромотора отдельно | Указывать, что именно: ДВС / электро / системная |
| Диапазоны «up to», «405–450 hp» | Признак ИИ-сгенерированного сайта | Не использовать источник вообще |

## Массы, размеры, буксировка

| Ловушка | Что делать |
|---|---|
| Curb weight (US) ≠ kerb weight (EU/AU): в ЕС снаряжённая включает 75 кг водителя, в США — нет | Указывать источник и стандарт; не сравнивать напрямую |
| Payload агрегатора отличается от заводского (JD Power 1427 vs Ford 1373 lb) | Брать производителя; расчёт полная − снаряжённая показывать как [Расчёт] |
| Длина зависит от бампера, кенгурятника, фаркопа, «L»-версии (Китай) | Длину/ширину/высоту брать одним набором из одного источника одной версии |
| Ширина «с зеркалами» vs «без» | Писать оба, если есть, и подписывать |
| Клиренс: 272 vs 265 vs 233 мм на разных сайтах для одной машины | Разные методики (под картером / под мостом / с нагрузкой). Брать официальную, остальное — в примечание |
| Угол съезда с фаркопом и без | Указывать оба |
| «33-дюймовые» шины при 285/70R17 (=32,7") | Писать размерность как факт, дюймы — как маркетинговое округление или [Расчёт] |
| Буксировка «when properly equipped» / с пакетом | Указывать, что нужен пакет; в блоке 13 — проверить наличие фаркопа/пакета по инвойсу |
| Кузов пикапа: длина «по полу» / «по верху» / «внутренняя» — три разные цифры | Подписывать, какая |

## Расход и динамика

| Ловушка | Что делать |
|---|---|
| Разные циклы: EPA / WLTP / NEDC / ADR / CLTC / JC08 — расхождение до 30% | Всегда цикл в скобках; не смешивать |
| 0–60 mph ≠ 0–100 км/ч | Не пересчитывать; писать как есть с пометкой |
| «Официально не публикуется» vs замеры прессы | Помечать источник цифры |
| Запас хода EV по CLTC на 20–30% больше WLTP | Цикл обязателен; для РФ карточек предпочтительно WLTP, если есть |

## Комплектация

| Ловушка | Что делать |
|---|---|
| Оснащение с другого рынка (подогрев руля, навигация, вентиляция сидений) | «По рынку»; в блок 13 — сверить с инвойсом |
| Оснащение с другой комплектации того же модельного ряда (сайт показывает «доступно на») | Различать «стандарт» / «опция» / «недоступно» |
| Число подушек: маркетинг «7» vs NCAP «6 + коленная» — считать по производителю данного рынка | Ставить по официальному сайту рынка версии |
| Диагональ экрана и число динамиков различаются по рынку/пакету | По рынку |
| Китайские названия комплектаций (豪华/尊贵/旗舰) переводятся по-разному в разных импортёрах | Давать оригинальное название + перевод |
| Модельный год vs год выпуска vs рестайлинг | Указывать МГ источника; если МГ отличается — [Уточнить] и проверить, что не было обновления |
| Цвета: палитра меняется каждый МГ и по рынку | «Сверить с инвойсом» всегда |

## Источники

| Ловушка | Что делать |
|---|---|
| auto-data.net / ultimatespecs — ошибки в об/мин, годах, иногда в единицах | Только для сверки |
| Сайты-«обзоры» с эмодзи-буллетами и общими фразами | Не источник; при обнаружении — закрыть |
| Дилерские страницы, копирующие пресс-релиз с ошибками | Найти оригинал на сайте производителя |
| PDF на Scribd и подобных | Использовать только чтобы найти оригинал у производителя; напрямую не цитировать |
| Страница производителя показывает соседнюю комплектацию (копипаст на сайте — Ford TH указал у Raptor 6 режимов от Wildtrak) | Сверять со вторым официальным источником; при расхождении — [Уточнить] с указанием обоих |
| Сниппет поиска обрезал таблицу | Всегда web_fetch полной страницы/PDF |
| JS-сайты (autohome, некоторые OEM) не отдают контент в fetch | Мобильная версия (m.autohome.com.cn), dongchedi, соседний рынок, поиск с другими словами |
| Пропущенная сноска «(1) при наличии пакета» / «(2) на 91-м бензине» | Читать сноски под таблицами и переносить условие в строку |

## Фотографии

| Ловушка | Как проявляется | Что делать |
|---|---|---|
| Дорестайл вместо рестайла (и наоборот) | Другая морда, фонари, бампер при том же названии модели | Сверять оптику/решётку с официальным фото именно этого МГ; при сомнении — отброс |
| Фото с чужого рынка | ROW/USA/GCC/China/RU: другой бампер, шильдики, оптика, накладки | Брать фото с рынка версии из шапки; иначе доказать идентичность внешности |
| Другой trim на фото | Топ-версия с обвесом/LED там, где спека про базу (или наоборот) | Сверять диски, оптику, решётку с комплектацией; несовпадение — отброс |
| Руль не с той стороны | LHD-фото салона для RHD-версии или наоборот | Салон — только со стороной руля как в спецификации |
| Цвет фото ≠ цвет лота/спеки | Студийное фото другого заводского цвета | Помечать [Фото-уточнить]; для конкретного лота цвет обязан совпадать → [УТОЧНИТЬ] |
| Картинка из выдачи без страницы-источника | Нет подписи — нельзя доказать год/рынок/trim | Не брать; открывать страницу-источник и читать подпись |
| Фото с классифайда/форума | Там перепутаны годы, рынки, битые/тюнингованные экземпляры | Не источник; только официальные пресс/конфигуратор/датированные тесты |
| ИИ-сгенерированное или рендер фаната | Нереальные детали, «AI generated», кривые шильдики | Отброс |
| Водяной знак чужого продавца | Фото уведёт клиента к конкуренту / вводит в заблуждение | Не использовать |
| Кузов/колёсная база перепутаны | Double Cab vs Single, SWB vs LWB, седан vs лифтбек | Сверять тип кузова и число дверей из блока 1 |

## Процесс

| Ловушка | Что делать |
|---|---|
| Ответ пишется из памяти модели без поиска | Правило: цифра без ярлыка S-n в файл не попадает |
| Фото подобрано до сборки ТТХ | Фотоподбор только после спецификации — иначе не с чем сверять версию |
| Фото приложено без доказательства версии | Правило: фото без доказанного соответствия (P-n + подпись) в файл не попадает |
| Бюджет поиска ушёл на второстепенное, а массы не найдены | Порядок сбора: двигатель → массы/габариты → комплектация → остальное |
| Файл создан, но не показан пользователю | present_files или явный путь |
| Шаблон нарушен (пропущен блок) | 13 блоков всегда, пустые — с пометкой |
| Слишком уверенная формулировка там, где источники расходятся | Оба значения + [Уточнить] + документ для проверки |
