# Источники, поисковые запросы, конвертация, чек-лист

## Иерархия источников

1. **Официальный сайт производителя на рынке версии** — страница модели / «Specifications» / «Technical data» / брошюра PDF / прайс-лист / конфигуратор («Build & Price» показывает точный состав комплектации и опций).
2. **Медиа/пресс-сайт производителя** — там лежат самые полные технические PDF (передаточные числа, тормоза, углы, массы по модификациям). Примеры: media.ford.com и fromtheroad.ford.com (US Tech Specs PDF), pressroom.toyota.com, media.gm.com, media.stellantis.com, press.bmwgroup.com, media.mercedes-benz.com, hyundainews.com, kianewscenter.com, global.toyota/newsroom, geelyauto.com, chery press.
3. **Тот же производитель на соседнем рынке той же версии** — тайская сборка → Австралия (ford.com.au, toyota.com.au) и Таиланд (ford.co.th); GCC → me.ford.com, toyota.ae; Европа → ford.de/ford.co.uk, toyota.de.
4. **Регуляторы и краш-тесты** — fueleconomy.gov / EPA (США), ANCAP (AU), Euro NCAP, IIHS, C-NCAP, KNCAP; российские ОТТС/СБКТС (реестр Росстандарта) — там официальные для РФ мощность и массы.
5. **Агрегаторы для сверки** — CarsGuide, CarExpert, Drive.com.au (AU); Edmunds, JD Power, Car and Driver (US); auto-data.net, ultimatespecs (глобально, аккуратно — бывают ошибки в об/мин и годах); autohome.com.cn, dongchedi.com (Китай — фактически официальные конфигурационные таблицы); danawa.com, encar.com (Корея); goo-net.com, carsensor.net (Япония); autoevolution.
6. **Не источники**: тексты дилерских сайтов, объявления на классифайдах, статьи-обзоры без ссылок на данные, ИИ-сгенерированные спецсайты (характерные признаки: эмодзи-буллеты, «up to», диапазоны мощностей, «зависит от версии»).

## Поисковые запросы (шаблоны)

- `<brand> <model> <year> specifications` / `technical specifications pdf` / `brochure pdf`
- `<brand> <model> <year> media technical specs` (пресс-сайт)
- `<brand> <model> <trim> <year> price list specification` (Азия/Европа: прайс-листы с оснащением)
- Рынковые: `<brand> <model> australia specs`, `<brand> <model> uae specifications`, `<品牌> <车型> 参数配置` (Китай: autohome), `<브랜드> <모델> 제원` (Корея), `<ブランド> <車名> 主要諸元` (Япония)
- Для сверки массы/буксировки: `<model> kerb weight GVM braked towing`, `<model> curb weight GVWR payload`
- Всегда открывай найденный PDF/страницу через web_fetch — сниппет режет таблицы.

## Конвертация единиц

| Из | В | Множитель / формула |
|---|---|---|
| in → мм | ×25,4 |
| ft → м | ×0,3048 |
| lb → кг | ×0,4536 |
| US gal → л | ×3,785 |
| lb-ft → Нм | ×1,356 |
| cu ft → л | ×28,32 |
| kW → л.с. (PS/DIN) | ×1,3596 |
| hp (SAE) → PS | ×1,0139 (обычно указывают как есть с пометкой «SAE») |
| л.с. (PS) → кВт | ×0,7355 |
| mpg (US) → л/100 км | 235,21 ÷ mpg |
| mph → км/ч | ×1,609 |
| 0–60 mph → 0–100 км/ч | не пересчитывать; указывать как есть с пометкой |
| psi → бар | ×0,0689 |

Округление: до целых мм и кг, до 0,1 л для баков и масла, до 1 л.с./Нм. Не «округляй красиво».

## Расчётные величины (маркируй [Расчёт])

- Грузоподъёмность = полная масса − снаряжённая масса (проверь, что обе с одного рынка и одной модификации).
- Полная масса автопоезда − полная масса = запас на прицеп (для сверки с заявленной буксировкой).
- Объём кузова/багажника в литрах из cu ft.
- Диаметр шины из размерности (285/70R17 ≈ 831 мм ≈ 32,7"), если производитель пишет «33-inch».

## Чек-лист перед выдачей

- [ ] Модельный год источника совпадает с запрошенным (или отмечено, что не менялось).
- [ ] Рынок каждой цифры понятен; версии не смешаны в одной колонке.
- [ ] Мощность: указано, PS/kW/SAE; л.с. и кВт согласованы (кВт × 1,36 ≈ л.с.).
- [ ] Момент: Нм и обороты; если источник в lb-ft — пересчитано.
- [ ] Массы: снаряжённая < полная < полная автопоезда; грузоподъёмность сходится с расчётом ±5 кг.
- [ ] Габариты: длина/ширина/высота/база из одного источника одной версии.
- [ ] Расход: указан цикл.
- [ ] Число подушек и диагональ экрана — с той же версии, не с соседней.
- [ ] Ключевые цифры (мощность, момент, массы, габариты, буксировка, бак) подтверждены минимум двумя источниками, из них хотя бы один — производитель.
- [ ] Всё, что есть только в агрегаторах или зависит от пакета/рынка — помечено [Уточнить] с указанием документа.
- [ ] Список источников с указанием, что откуда взято.
- [ ] Нет цитат из брошюр длиннее пары слов — цифры и факты своими словами.
- [ ] Фото (если приложены): у каждого доказано соответствие модификации (МГ, рынок, поколение/рестайлинг, кузов, trim, руль) по подписи/деталям; ярлык P-n со страницей-источником.
- [ ] Фото не с классифайда/форума/выдачи без подписи, не ИИ-рендер, без чужих водяных знаков.
- [ ] Цвет каждого фото сверён с блоком 12; отличия помечены. Для конкретного лота несовпадение цвета/дисков вынесено в [УТОЧНИТЬ].
