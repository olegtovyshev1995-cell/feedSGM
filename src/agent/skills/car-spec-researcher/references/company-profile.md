# Профиль компании для блока доверия

Заполни один раз со слов пользователя (или попроси прислать). Пока пустые строки — в объявление идут плейсхолдеры `[УТОЧНИТЬ: …]`, а не выдуманные факты. Блок доверия строится только из строк со статусом «подтверждено».

| Поле | Значение | Статус |
|---|---|---|
| Название компании / бренд | | не подтверждено |
| Юрлицо / ИНН (по желанию для текста «работаем по договору») | | не подтверждено |
| Город, адрес шоурума / площадки | | не подтверждено |
| С какого года на рынке / сколько машин поставлено | | не подтверждено |
| Направления: новые / б/у, в наличии / под заказ, рынки (ОАЭ, Китай, Корея, США, Европа) | | не подтверждено |
| Документы: ЭПТС, СБКТС, растаможка, договор, что оформляет компания | | не подтверждено |
| Гарантия (чья, срок, что покрывает) | | не подтверждено |
| Оплата: наличные, безнал, лизинг, кредит, trade-in, для юрлиц | | не подтверждено |
| Доставка: регионы, сроки, стоимость | | не подтверждено |
| Отзывы: где (Авито-рейтинг, Яндекс, 2ГИС), сколько, оценка | | не подтверждено |
| Сервис после покупки: ТО, запчасти, дооснащение (русификация, обогревы) | | не подтверждено |
| Что показываем до сделки: фото/видео конкретной машины, VIN, осмотр | | не подтверждено |
| Ограничения / что нельзя обещать | | не подтверждено |

Как получать данные: если профиль пуст — задай пользователю один вопрос списком из этих полей и предложи прислать текст «о компании» или ссылку на сайт/страницу Авито; факты с сайта пометь «с сайта компании, подтвердить». После заполнения обновляй профиль, а не переспрашивай каждый раз.

Формулировки для объявления — факт, а не оценка: «поставили 240 автомобилей с 2019 года» вместо «большой опыт»; «оформляем ЭПТС и СБКТС, вы получаете машину на учёте» вместо «полное сопровождение».

# Карта «есть → значит получите»

Как превращать характеристику в выгоду. Правило: выгода следует из факта напрямую, без домыслов и оценок; если из факта польза не выводится однозначно — оставь только факт.

| Есть (характеристика) | Значит получите (выгода) |
|---|---|
| Мощность X л.с., момент Y Нм при N об/мин | Уверенный разгон с полной загрузкой и прицепом; тяга «снизу» (если момент на низких оборотах) |
| Два турбокомпрессора / битурбо | Ровная тяга без провала на низких оборотах |
| Понижающий ряд, блокировки дифференциалов | Выезд из грязи, снега, песка без буксира |
| Клиренс X мм, брод Y мм, углы въезда/съезда | Проезд по колее, бродам, съезд с бордюров без задевания |
| Адаптивные амортизаторы (FOX Live Valve, Bilstein, магнитные) | Мягко по трассе, собранно на бездорожье — без ручных настроек |
| Задняя пружинная подвеска вместо рессор | Комфорт как у внедорожника, а не грузовика |
| Полный привод с автоматическим режимом (4A / AWD) | Не нужно переключать режимы зимой в городе |
| Режимы движения (снег, песок, грязь) | Одна кнопка вместо опыта — электроника подстраивает газ, коробку, тормоза |
| Матричные / адаптивные LED-фары | Дальний не слепит встречных и не выключается — видно дорогу дольше |
| Круиз-контроль адаптивный со Stop&Go + удержание в полосе | Меньше усталости в пробке и на трассе |
| Автоторможение, контроль слепых зон, камера 360° | Меньше риска ДТП при парковке и перестроении, дешевле КАСКО |
| N подушек безопасности | Защита водителя, пассажира и второго ряда |
| Электрорегулировки сидений, память, подогрев / вентиляция | Каждый водитель садится в свою посадку кнопкой; тепло зимой / не жарко летом |
| Двухзонный климат + дефлекторы второго ряда | Комфорт всем, а не только водителю |
| Экран X" с беспроводными CarPlay/Android Auto | Навигация и музыка с телефона без проводов |
| Розетка 230 В / 400 Вт в кузове и салоне | Питание инструмента, ноутбука, холодильника на выезде |
| Бак X л при расходе Y л/100 км | Пробег ~Z км без заправки [Расчёт] |
| Грузоподъёмность X кг, буксировка Y кг | Что реально можно везти: прицеп с лодкой/техникой (не преувеличивать) |
| Габариты кузова пикапа | Что помещается по факту (например, европаллета — только если ширина между арками ≥ 1200 мм и это подтверждено) |
| Полноразмерная запаска | Не застрянете в дальней поездке из-за прокола |
| Заводская гарантия X лет / Y км (если действует в РФ — только по подтверждению) | Указывать только при подтверждении, кто её обеспечивает |
| Рамная конструкция | Тянет прицеп и держит нагрузку без усталостных деформаций кузова |
| Стальная защита днища | Картер, раздатка и бак защищены на бездорожье |

Что не превращать в выгоду: маркетинговые названия без цифр, цвета отделки, «спортивный дизайн» — их можно упомянуть как факт, но не как пользу.
