# Шаблон итогового файла спецификации

Файл `<Марка>_<Модель>_<год>_spec.md`. Структура обязательна (14 блоков); блоки не переставлять и не пропускать. Если в блоке нет данных — оставь заголовок и напиши «нет данных в открытых источниках». В каждой строке таблицы последняя колонка — статус: [Факт] / [Расчёт] / [Уточнить] и ярлык источника (S1, S2…). Оригинальное значение до конвертации — в скобках: «2433 кг (5363 lb, S2)».

Если модель различается по рынкам — в разделах 2, 6, 7, 10 делай две колонки значений (например «ROW» и «USA»), в остальных пиши «по рынку» рядом с пунктом.

```markdown
# <Марка> <Модель> <модификация> — <год> модельный год

Полная спецификация для карточек на Авито / Auto.ru / Drom.

## ВАЖНО перед заполнением карточек
<2–6 строк: сколько заводских версий, откуда вероятнее всего ввоз, что различается, что сверить с ПТС/СБКТС/инвойсом. Если версия одна — так и напиши.>

| | Версия A (<рынки>) | Версия B (<рынки>) |
|---|---|---|
| Завод / страна сборки | | |
| Мощность (заводская) | | |
| Крутящий момент | | |
| Бак | | |
| Длина / высота | | |
| Снаряжённая / полная масса | | |
| Подушки | | |
| Мультимедиа | | |
| Комплектации / пакеты | | |

## 1. Общее
| Параметр | Значение | Статус / источник |
Марка / модель · Поколение (заводской код, годы выпуска) · Модельный год · Тип кузова, число дверей · Мест · Конструкция (несущий кузов / рама) · Класс · Руль (L/R по рынкам) · Комплектация/trim и что в неё входит по умолчанию · Гарантия завода по рынкам

## 2. Двигатель
Тип и обозначение (заводской код) · Рабочий объём, см³ · Цилиндры / расположение · Клапанов, ГРМ · Наддув · Впрыск · Диаметр × ход · Степень сжатия · Макс. мощность (л.с./кВт при об/мин, с указанием стандарта — PS/DIN, SAE, ГОСТ) · Макс. момент (Нм при об/мин) · Топливо и октан · Объём масла / ОЖ · Экокласс · Старт-стоп · Гибридная система (если есть: тип, ёмкость батареи, мощность электромоторов, суммарная мощность) · Для EV: батарея кВт·ч, тип, мощность моторов, зарядка AC/DC кВт, запас хода по циклу

## 3. Трансмиссия и привод
КПП: тип, число ступеней, обозначение · Передаточные числа (если найдены) · Привод и тип системы полного привода · Раздаточная коробка / понижающий ряд · Блокировки · Режимы движения · Внедорожные ассистенты (Trail Control, HDC и т.п.)

## 4. Подвеска, рулевое, тормоза
Передняя / задняя подвеска (тип, амортизаторы) · Рулевое (тип, передаточное число) · Диаметр разворота · Тормоза перед/зад (диаметр × толщина, суппорты) · Стояночный тормоз

## 5. Колёса и шины
Диски (размер, материал) · Шины (размер, тип, при известности — марка) · Запасное колесо · TPMS

## 6. Размеры и массы
Длина · Ширина без/с зеркалами · Высота · База · Колея П/З · Клиренс · Углы въезда/съезда/рампы · Брод · Свесы · Снаряжённая масса · Полная масса · Полная масса автопоезда · Грузоподъёмность · Прицеп с/без тормозов · Вертикальная нагрузка на фаркоп · Бак
### Грузовая платформа / багажник (длина, ширина, между арками, высота борта, объём; для легковых — объём багажника мин/макс)
### Салон (пространство над головой, для ног, по плечам П/З)

## 7. Динамика и расход
0–100 км/ч (с указанием источника: официально / замеры прессы) · Макс. скорость · Расход по циклу (WLTP / NEDC / ADR / EPA / CLTC — обязательно указать цикл) · CO₂

## 8. Экстерьер
Маркированный список фактического оснащения: оптика, зеркала, стёкла, крыша, рейлинги, подножки, защита, буксировочные элементы, тип заправки и т.п. «По рынку» там, где различается.

## 9. Интерьер
Сиденья (материал, регулировки, подогрев/вентиляция/память) · Руль · Климат · Приборная панель · Мультимедиа (диагональ, ОС, CarPlay/AA, навигация, OTA) · Аудио (бренд, число динамиков) · Розетки/USB/зарядка · Доступ и запуск · Подсветка, зеркала, стеклоподъёмники · Прочее

## 10. Безопасность
Подушки (число и расположение) · Активные системы (ABS, ESP и т.д.) · Крепления детских кресел · Противоугонные · Рейтинг краш-тестов, если есть (NCAP/IIHS, год)

## 11. Ассистенты водителя (ADAS)
Список с точными названиями производителя и кратким переводом функции.

## 12. Цвета кузова и салона
Заводские названия, отметить эксклюзивные для комплектации; «палитра различается по рынкам, сверять с инвойсом».

## 13. Что обязательно сверить с документами партии
Список пунктов [Уточнить] с указанием документа: ПТС/СБКТС (мощность, масса, экокласс), инвойс (комплектация, цвет), VIN-декодер (пакеты опций).

## 14. Фотографии (реестр)
Изображения, у которых доказано соответствие модификации. Каждое фото — строкой; несоответствие по цвету/trim/МГ отмечать в статусе. Фото без доказательства не приводить.
| P-n | Что изображено (ракурс) | Ссылка / источник | Чем подтверждено соответствие (МГ, рынок, поколение, trim, руль) | Цвет | Статус |
|---|---|---|---|---|---|
Статусы: [Фото-факт] — пресс/официальный источник, подпись подтверждает версию; [Фото-уточнить] — внешность совпадает, но что-то не доказано жёстко (соседний МГ, иной цвет, trim не виден). Если ни одного подходящего фото — написать «фото с доказанным соответствием не найдено».

## Источники
S1, S2, … — список ссылок ТТХ с указанием, что взято из каждого (рынок, дата/версия документа).
P1, P2, … — список ссылок на фото с указанием подписи/страницы-источника, доказывающей версию.
```

## Что делает файл хорошим

- Каждая цифра — с единицей и статусом.
- Отличия по рынкам вынесены в первый блок, а не спрятаны в примечаниях.
- Расчётные величины помечены и воспроизводимы (грузоподъёмность = полная − снаряжённая).
- Раздел 13 даёт продажам и выкладке конкретный список, что проверить, а не общее «уточняйте».
