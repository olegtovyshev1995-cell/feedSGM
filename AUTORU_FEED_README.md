# feed.php — фид автозагрузки Авто.ру (легковые, с пробегом)

Готовый PHP-скрипт: кладётся рядом с `import-pdo.php`, берёт авто из той же
MySQL, что и сайт, и отдаёт XML-фид в формате автозагрузки Авто.ру по
постоянному URL. Авто.ру сам забирает фид по расписанию (модель pull —
файл никуда не «загружается» вручную).

## Что залить на сайт

| Файл | Назначение |
|---|---|
| `feed.php` | сам генератор (единственный скрипт) |
| `feed.config.php` | параметры БД — создаётся из `feed.config.example.php`, **в git не попадает** |

`autoru.xml` и `feed.log` скрипт создаёт сам на сервере — заливать не нужно.

## Установка (5 минут)

1. Скопируйте `feed.php` и `feed.config.example.php` в ту же папку, где лежит
   `import-pdo.php` (обычно корень сайта).
2. Скопируйте конфиг и впишите доступ к БД (те же, что у `import-pdo.php`):
   ```bash
   cp feed.config.example.php feed.config.php
   # затем отредактируйте feed.config.php (host/name/user/pass)
   ```
   Проще всего — переиспользовать существующий `config.core.php`
   (см. «Вариант А» внутри `feed.config.example.php`), тогда креды не
   дублируются.
3. Откройте вверху `feed.php` блок **НАСТРОЙКА** и сверьте со своей таблицей:
   - `FEED_TABLE` — имя таблицы с авто;
   - `FEED_COLUMNS` — какое поле Авто.ру берётся из какой вашей колонки;
   - `FEED_PHOTOS` — как хранятся фото (`delimited` — список в одной колонке,
     или `table` — отдельная таблица);
   - `FEED_ACTIVE` — как отличать «в наличии» (по умолчанию — все строки,
     т.к. `remove_csv.php` удаляет проданные).

   > Проверить схему: `SHOW CREATE TABLE ваша_таблица;` — по нему поправьте
   > имена колонок в `FEED_COLUMNS`.

## URL фида

После заливки фид доступен по адресу:

```
https://sgmautogroup.ru/feed.php
```

Проверьте в браузере — должен открыться XML `<data><cars><car>…`.

## Что вставить в кабинете Авто.ру

`cabinet.auto.ru → Фиды → Автоматическая (по ссылке)` → указать URL:
`https://sgmautogroup.ru/feed.php`. Раздел — **«С пробегом» (легковые)**.
Ссылку регистрируют один раз; дальше Авто.ру опрашивает её по расписанию.

## Как это защищено (из требований)

- **Только PDO prepared** — никакой конкатенации значений в SQL; имена
  колонок из конфига дополнительно валидируются (`[A-Za-z0-9_]`).
- **Креды из конфига**, не в коде; `feed.config.php` в `.gitignore`.
- **Экранирование** `" & > < '` и вырезание запрещённых управляющих
  символов; `Content-Type: application/xml; charset=utf-8`.
- **Валидация каждой строки**: нет обязательного поля (цена, VIN/unique_id,
  модификация-или-двигатель, пробег, год…) → авто пропускается и пишется в
  `feed.log`, а не уходит битым.
- **Защита от пустого фида**: если БД недоступна, вернула 0 строк или все
  строки отбракованы — скрипт **не** отдаёт пустой валидный XML (Авто.ру
  понял бы его как «снять все объявления»), а отдаёт последний валидный
  `autoru.xml` из кэша, иначе HTTP 500.
- **Лог** (`feed.log`): сколько прочитано, сколько попало в фид, сколько
  отброшено и по каким причинам.

## Соответствие спеке Авто.ру (легковые, с пробегом)

- Каркас `<?xml …?><data><cars><car>…`, теги строчными, UTF-8.
- `vin` — 17 символов, латиница+цифры, без I/O/Q; если нет — `unique_id`.
- `price` — целое > 1500; `run` > 0; `year` ≥ 1970; `registry_year` ≥ year.
- Строгие справочники нормализуются: `body_type`, `color`, `wheel`,
  `custom`, `state`, `owners_number`, `availability`, `currency`,
  `engine_type`, `gearbox`, `drive`.
- **`modification_id` и параметры двигателя не отправляются вместе** (запрет
  спеки): если задан `modification_id` — движок-теги опускаются; иначе
  отправляются `engine_volume/power/type/gearbox/drive`.
- `images` — до 40 ссылок, `<images><image>URL</image>…</images>`.

## Переключение на статический autoru.xml по CRON

По умолчанию фид генерируется на лету при каждом запросе. Если каталог
вырастет и генерация станет тяжёлой — переключитесь на статический файл:

1. Раз в N минут запускайте скрипт из CLI (он запишет `autoru.xml`):
   ```
   */15 * * * * /usr/bin/php /path/to/feed.php >/dev/null 2>>/path/to/feed.log
   ```
   (в CLI-режиме `feed.php` только пишет `autoru.xml`, ничего не отдаёт в stdout).
2. В кабинете Авто.ру укажите ссылку на статический файл:
   `https://sgmautogroup.ru/autoru.xml`.

Так Авто.ру читает готовый файл, а тяжёлый запрос к БД выполняется по
расписанию, а не на каждый заход.
