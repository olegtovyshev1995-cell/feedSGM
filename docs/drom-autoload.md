# Drom — автозакачивание объявлений (легковые авто)

Конспект официальной инструкции `https://www.drom.ru/misc/autoload/`
(снят 21.08.2026). Держим офлайн-копию: страница закрыта для части сред
сборки, а маппер `src/mappers/drom.py` должен сверяться с первоисточником.

Справочник: `data/refs/drom_ref.xml` (свежая версия —
`www.drom.ru/cached_files/autoload/files/ref.xml`).
XSD для валидации: `www.drom.ru/autoload/files/drom_autoload.xsd`.

## Модель работы

- Обмен — XML-файлом (в инструкции `bulls.xml`, имя любое). Кодировка
  указывается в заголовке XML и должна совпадать с кодировкой данных.
- **Pull:** Дром сам опрашивает вашу ссылку. Стандартная частота —
  **15–60 минут**.
- **Все объявления, которых нет в текущем файле, удаляются автоматически.**
  Продано → просто убрать `<Offer>` из файла.
- Изменённые данные — обновляются. Чтобы объявление **обновилось, а не
  создалось заново**, должно совпасть **любое** из полей: **`VIN`** или
  **`idOffer`**.
- Редактировать объявление вручную в кабинете нельзя — только через файл.
- Подключение: письмо на `client@drom.ru` (или менеджеру) со ссылкой на
  файл, **ID кабинета на Дроме** и **e-mail для отчётов**. Заявка — до
  3 рабочих дней. Отчёты — в кабинете и на почту.
- Уже размещённые объявления при совпадении VIN заменяются без повторного
  списания; объявления из архива поднимаются за половину стоимости.

## Структура файла

```xml
<?xml version="1.0" encoding="utf-8"?>
<avtoxml>
  <lastBuildDate>…</lastBuildDate>   <!-- дата/время создания файла -->
  <Offers>      <!-- легковые авто:      <Offer>     -->
  <SpecOffers>  <!-- грузовики/спец:     <SpecOffer> -->
  <MotoOffers>  <!-- мототехника:        <MotoOffer> -->
  <Discounts>   <!-- скидки, опционально -->
</avtoxml>
```

## Секция `Offer` — поля

Все поля с префиксом `id*` — числовые идентификаторы из `ref.xml`.
**Жирным в инструкции помечены обязательные.** Значения, которых нет в
справочнике, приводят к тому, что объявление не будет добавлено (либо
поле окажется пустым).

| Поле | Обяз. | Значение |
|---|:--:|---|
| `idOffer` | **да** | уникальный id объявления в вашей базе |
| `idMark` | **да\*** | id марки; \*если id указать не можете — текстом в `sMark` |
| `idModel` | **да\*** | id модели; \*иначе текстом в `sModel` |
| `sMark` | **да\*** | название марки (Toyota, BMW) — обязательно, если нет `idMark` |
| `sModel` | **да\*** | название модели (Land Cruiser, X5) — обязательно, если нет `idModel` |
| `idModification` | нет | id модификации |
| `idCountry` | нет | id страны, где находится авто (по умолчанию 0) |
| `idCity` | **да\*** | id города, в котором находится авто |
| `sCity` | **да\*** | название города (из справочника) |
| `YearOfMade` | **да** | год выпуска, 4 цифры |
| `VIN` | **да** | VIN или номер кузова |
| `Price` | **да** | цена в рублях |
| `idCurrency` | нет | id валюты |
| `NewType` | нет | 1 — новый, 0 — с пробегом |
| `Volume` | нет | объём двигателя, куб. см |
| `FrameType` | нет | тип кузова (id из справочника) |
| `Color` | нет | цвет кузова (id из справочника) |
| `idTransmission` / `sTransmission` | нет | тип трансмиссии |
| `idEngineType` / `sEngineType` | нет | тип двигателя |
| `idHybridType` / `sHybridType` | нет | гибрид (да/нет) |
| `idGbo` / `sGbo` | нет | ГБО (да/нет) |
| `idDriveType` / `sDriveType` | нет | тип привода |
| `idWheelType` / `sWheelType` | нет | положение руля (левый/правый) |
| `Haul` | нет | пробег, км |
| `idHaulRussiaType` | нет | 1 — с пробегом по РФ, 0 — без |
| `NumberOfOwners` | нет | количество владельцев |
| `sComplectation` / `idComplectation` | нет | комплектация (по каталогу Дрома) |
| `Additional` | нет | текстовое описание ТС; можно ссылку на видео YouTube |
| `Photos` | нет | секция со списком фото (см. ниже) |
| `Phone` | нет | телефон, **не более 20 символов** |
| `Whereabouts` | нет | в наличии / в пути / под заказ (id из справочника) |
| `Power` | нет | мощность, л.с. |
| `idCertProgram` | нет | программа сертификации |
| `DamagedType` | нет | 0 — небитый, 1 — битый или не на ходу |
| `SOR` | нет | номер СТС для авто с пробегом (10 символов) |

### Правило раздела публикации (город + страна)

На Дроме два раздела продажи легковых:

1. **Продажа в России** — авто в РФ **либо** будет привезено из-за рубежа
   в город РФ, и цена включает доставку/растаможку. Во втором случае:
   `idCountry` = страна текущего нахождения, `idCity` = город РФ, куда
   привезут (в объявлении покажется «Сингапур → Владивосток»).
2. **Авто под заказ** — авто за рубежом, цена **без** доставки и пошлин.
   Тогда `idCountry` = страна нахождения, **`idCity` = 0**.

> «Убедительно просим вас соблюдать эти правила и размещать объявления в
> соответствующих разделах! В случае нарушений правил размещения будут
> приниматься меры, вплоть до удаления объявлений с сайта.»

## Секция `Photos`

```xml
<Photos PhotoDir="{сайт и директория с фотографиями}"
        PhotoMain="{файл главного фото}">
  <Photo>{фото 1}</Photo>
  …
  <Photo>{фото N}</Photo>
</Photos>
```

- Расширения — `.jpg` / `.jpeg`. Нет фото → секцию можно опустить.
- `PhotoDir` — префикс, добавляемый ко всем адресам (в т.ч. к главному).
- `PhotoMain` — имя главного фото; если его нет в списке, будет добавлено.
- Схема «**одно фото — одна ссылка**». Фото загружаются **один раз**:
  чтобы обновить — выложить по новой ссылке и заменить ссылку в файле.
- Не менять директории/имена, если содержимое не изменилось.
- Не добавлять в URL меняющиеся параметры (timestamp) — замедляет обработку.
- Имя фото лучше делать хеш-суммой содержимого:
  `<Photo>5d41402abc4b2a76b9719d911017c592.jpg</Photo>`.
- Фото могут загрузиться не сразу; если за 1–2 часа не появились —
  `client@drom.ru`.

## Секция `Discounts` (только новые авто у офдилеров)

Нужна, если карточке продавца присвоен статус «Официальный дилер».

```xml
<Discount>
  <idDiscount>уникальный id скидки</idDiscount>
  <VIN>VIN или номер кузова</VIN>
  <discount>размер скидки</discount>
  <idDiscountType>1 — %, 2 — рубли</idDiscountType>
  <name>название скидки</name>
  <description>описание скидки</description>
</Discount>
```

`MaxDiscount` (`idMaxDiscount`, `VIN`, `maxDiscount`, `idDiscountType`) —
максимально возможная скидка, когда условия нельзя применить одновременно;
названия у такой скидки нет.

## Видео

Ссылка на ролик YouTube — в поле `Additional` секции `Offer`; видео
появится рядом с фотографиями.

## Справочник `ref.xml`

Разделы: `Marks`, `Models` (модель знает свой `idMark`), `Cities`,
`NewTypes`, `FrameTypes`, `Colors`, `Transmissions`, `EngineTypes`,
`HybridTypes`, `DamagedTypes`, `sGboTypes`, `DriveTypes`, `WheelTypes`,
`HaulRussiaTypes`, `WhereaboutsTypes`, `Markets`, `CertPrograms`,
`DiscountTypes`, `Currencies`.

Ключевые перечисления (из `data/refs/drom_ref.xml`):

- `FrameType`: 10 Седан, 3 Универсал, 1 Купе, 5 Хэтчбек 5 дв., 4 Хэтчбек 3 дв.,
  6 Минивэн/Микроавтобус, 7 Джип/SUV 5 дв., 8 Джип/SUV 3 дв., 12 Пикап,
  11 Открытый, 9 Лифтбек
- `Color`: 1 чёрный, 2 фиолетовый, 3 синий, 4 серый, 5 оранжевый, 6 красный,
  7 коричневый, 8 золотистый, 9 зелёный, 10 жёлтый, 11 бордовый, 12 белый,
  13 бежевый, 14 голубой, 15 розовый, 16 серебристый
- `idTransmission`: 1 механическая (MT), 2 автомат (AT)
- `idEngineType`: 1 бензин, 2 дизель, 4 электромотор
- `idDriveType`: 1 передний, 2 задний, 3 полный (4WD)
- `idWheelType`: 1 правый, 2 левый
- `Whereabouts`: 0 в наличии, 1 в пути, 2 под заказ
- `idCurrency`: 0 usd, 1 rub, 2 eur, 3 yen, 4 cny, 5 krw, 6 kzt, 7 byn
- `NewType` / `idHybridType` / `idGbo` / `DamagedType` / `idHaulRussiaType`:
  0 — нет, 1 — да

Модельные ряды в справочнике **не включают комплектации**: есть
`Hyundai Avante`, но не `Hyundai New Avante XD`; Mercedes-Benz — линейками
(`A-Class`, `B-Class`). Недостающие марки/модели/города — запросом на
`client@drom.ru`.

Города в справочнике уникальны по названию; неоднозначные названия
записаны с регионом — `Красногорск, Московская область`.

## Официальный пример vs таблица полей — расхождения

Пример Дрома лежит в `docs/examples/drom_bulls_example.xml`. Он расходится
с таблицей полей инструкции; **источником правды по именам считаем пример
и `ref.xml`**, короткие формы из таблицы поддерживаем как синонимы.

| В таблице инструкции | В примере и в `ref.xml` |
|---|---|
| `NewType` | `idNewType` / `sNewType` |
| `FrameType` | `idFrameType` / `sFrameType` |
| `Color` | `idColor` / `sColor` |
| `DamagedType` | `idDamagedType` / `sDamagedType` |
| `Whereabouts` | `Whereabouts` / `sWhereabouts` |
| `idHaulRussiaType` | `idHaulRussiaType` / `sHaulRussiaType` |
| — | **`Phone2`** — второй телефон, в таблице полей отсутствует |

Прочее из примера:

- **Порядок тегов внутри `Offer` не строгий:** в примере `Photos` идёт
  *перед* `Additional`, а `VIN` — последним тегом. Таблица инструкции даёт
  другой порядок. Значит `xs:sequence` можно не соблюдать.
- **`lastBuildDate` в примере отсутствует** — секция необязательная.
- `PhotoDir=""` + абсолютные URL в `PhotoMain`/`Photo` работают наравне с
  «префикс + имена файлов».
- В `Discounts` тип скидки тоже двойной: `idDiscountType` или
  `sDiscountType` (`руб.` / `%`). У `MaxDiscount` название не задаётся.
- Для новых авто (`idNewType` = 1) в примере `Haul` = 0.

## Что важно для «расшивки» по региону

`VIN` — обязательное поле **и** ключ обновления. Несколько `Offer` с
одинаковым VIN — это, с точки зрения Дрома, одно и то же объявление,
которое будет переписываться, а не размещаться в каждом городе.
