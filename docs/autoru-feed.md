# Auto.ru — прайс-лист (фид) для легковых автомобилей

Конспект официальной справки Авто.ру (сохранена офлайн:
`docs/examples/autoru_cars_help.html` — требования к прайс-листу легковых,
`docs/examples/autoru_feeds_help.html` — загрузка фида). Домены Яндекса
закрыты для части сред сборки, поэтому держим копию рядом с маппером
`src/mappers/autoru.py`.

## Модель работы

- Прайс-лист — XML, заголовок `<?xml version="1.0" encoding="utf-8"?>`,
  корень `<data><cars><car>…`.
- **Имена элементов только строчными** (`image`, не `Image`).
- Спецсимволы `< > &` в тексте кодировать; первые 32 ASCII-символа
  (кроме таб/перевод строки/возврат каретки) в текстовых полях запрещены.
- **Pull или ручная загрузка.** Кабинет `cabinet.auto.ru` → **Фиды** →
  категория + тип загрузки. Автоматическая: URL фида на сайте/сервере —
  **ссылки на файлообменники и облачные хранилища не принимаются**. При
  изменениях фид обновляется через час, без изменений — через 6 часов.
- **Нельзя два типа загрузки на одну категорию** (нельзя авто + ручной в
  «Легковые с пробегом» одновременно).
- Опция «Удалять объявления» при загрузке — убирает объявления, которых
  нет в новом фиде (аналог поведения Drom, но управляется галочкой).

## Ключ обновления объявления

Объявление обновляется, если совпали: **mark, model, tech_param_id
(только легковые), year, color, VIN или uniq_id**. Любое расхождение →
новое объявление. Удалённое через автозагрузку восстановимо 30 суток.

## Два раздела: «Новые» и «С пробегом»

Раздел определяется составом полей:

| Только «С пробегом» | Только «Новые» |
|---|---|
| `state`, `owners_number`, `run`, `registry_year`, `sts`, `warranty_expire` | `owners_number` = «Не было владельцев» |

`complectation_name` обязателен для «Новых» (если у марки есть комплектации).

## Важное про регион и «расшивку»

**В фиде нет поля «город объявления».** Регион объявления определяется
регионом дилерского салона в кабинете. `poi_id` задаёт адрес осмотра, но
адрес, отличный от салона, включается только через поддержку Авто.ру.
Легальный способ показать несколько городов в ОДНОМ объявлении —
`delivery_info` (до 10 адресов доставки).

Поэтому «одна машина по всем городам области» как отдельные объявления на
Авто.ру фидом **не делается** (в отличие от Drom, где `idCity` есть в
каждом Offer). Штатно: одно объявление на автомобиль + `delivery_info`.

## Правила для фото (отличие от Drom)

Только **JPG**, соотношение **4:3** (иначе обрежут), ≤ 20 МБ, ≤ 40 шт.
Меняешь картинку — меняй ссылку (по старой ссылке обновление не подхватит).
