Требования к передаче данныхТребования к передаче данных

Для размещения объявлений на Авто.ру необходимо составить прайс-лист в формате XML (Extensible Markup Language).

Формат XML не позволяет использовать первые 32 ASCII-символа в текстовых полях. Исключения — табуляция, перевод строки, возврат каретки. Также стандарт строго требует кодировать в тексте следующие символы:

Символ, который нужно заменить

Код для файла XML

"

&quot;

&

&amp;

>

&gt;

<

&lt;

'

&apos;

Кодировка: UTF-8.

Прайс-лист в формате XML должен начинаться с нулевого символа первой строки со стандартного заголовка.

<?xml version="1.0" encoding="utf-8"?>

В названиях элементов нельзя использовать заглавные буквы. Например, элемент Image не будет обработан, image — будет.

Требования к объявлениямТребования к объявлениям

Перед составлением прайс-листа ознакомьтесь с Правилами составления объявлений.

Корневой элемент data содержит родительский элемент cars. В cars входят элементы car, каждый из которых содержит информацию из одного объявления.

Внимание

Элементы со строго ограниченным набором значений могут содержать только перечисленные варианты. Использование других значений приведет к ошибке при обработке прайс-листа.

Размер файла каталога более 20 МБ. Рекомендуем открывать его в текстовых редакторах, например Notepad++ для Windows и Sublime Text для Mac OS.

Внимание

Каталог Авто.ру регулярно обновляется. Рекомендуем следить за изменениям и вовремя редактировать свои прайс-листы. Объявления с устаревшими данными перестают отображаться на сайте.

credit_discount

insurance_discount

Скидка при покупке со страховкой.

tradein_discount

Скидка про покупке по программе Trade-In.

max_discount

Максимальная суммарная скидка на автомобиль, возможная при выполнении условий всех действующих в этот момент акций.

Примечание

Скидка не может быть больше 40% от заявленной стоимости автомобиля.

images

Фотографии.

Можно передавать несколько элементов.

<images>
          <image></image>
          <image></image>
        </images>

Максимальное количество — 40 фотографий.

Формат — JPG.

Размер одного файла — не более 20 Мб.

Соотношение сторон фотографии — 4:3 (фото с другими пропорциями будет автоматически обрезано).

Чтобы изменить изображение в объявлении, вставьте новую ссылку. Обновленное фото по прежней ссылке не будет загружено.

Внимание

Не меняйте ссылки на фотографии, если вам не требуется заменить сами фото. Обработка фотографий замедляет загрузку прайс-листа и объявления будут отображаться без них.

Элемент указывается, если к объявлению должны быть применены дополнительные услуги.

Возможные значения:

  • premium;
  • special;
  • package_turbo

service_auto_apply

Набор элементов, характеризующих автоприменение услуги «Поднятие в поиске».

Услуга платная. Актуальная цена указана в разделе Стоимость размещения.

<service_auto_apply>
          <fresh>
            <switch/>
            <weekdays/>
            <time/>
            <frequency/>
          </fresh>
        </service_auto_apply>

fresh

Услуга «Поднятие в поиске».

Во вложенных элементах следует передавать условия оказания услуги.

switch

Подключение или отключение услуги.

Возможные значения:

  • on;
  • off.

После подключения услуга предоставляется регулярно на выбранных условиях.

Чтобы отключить услугу, следует изменить значение элемента на off. Если удалить элемент из прайс-листа, услуга не отключится.

weekdays

Дни недели, когда применяется услуга.

Следует передавать порядковый номер дня недели от 1 до 7.

Например, если значение элемента 1, 3, 5, то объявление поднимется в поиске в понедельник, среду и пятницу.

time

Время поднятия объявления в формате 00:00:00.

frequency

Частота оказания услуги по часам.

В качестве значения используется число от 1 до 24.

Например, если значение элемента 2, то объявление будет подниматься один раз в два часа.

Если переданы элементы time и frequency, учитывается только frequency.

badges

Услуга Стикеры.

Элемент указывается, если к объявлению должна быть применена услуга «Стикеры».

Услуга платная. Актуальная цена указана в разделе Стоимость размещения.

К одному объявлению можно добавить не более трех стикеров.

Название стикера следует передавать во вложенном теге name. Названия приведены в списке возможных стикеров или можно указать их самостоятельно.

В названии стикера можно использовать максимум 25 символов.

<badges>
          <badge>
            <name/>
          </badge>
        </badges>

contact_info

Набор элементов о контактах.

<contact_info>
          <contact>
            <name/>
            <phone/>
            <sip_url/>
            <time/>
          </contact>
        </contact_info>

sip_url (SIP-адрес) необходим для передачи на АТС дилера номера телефона пользователя, соединение с которым устанавливает Авто.ру по заявке на обратный звонок.

contact

Данные контактного лица.

name

Имя контактного лица.

phone

Номер телефона контактного лица.

Пример: 80123456789.

time

Время работы в виде интервала: 00:00-23:59.

warranty_expire

Срок истечения гарантии.

Следует передавать месяц и год.

Можно применить только в разделе «С пробегом».

Пример: 03.2017.

warranty_type

Тип гарантии.

Значения:

  • Гарантия производителя.
  • Гарантия дилера.
  • Уточняйте условия гарантии (для случаев, когда гарантия отсутствует или отличается от привычных условий).

Пример:

<warranty_type>Гарантия дилера</warranty_type>

sts

Серия и номер СТС.

Можно указать только в разделе «В пробегом».

Пример: 77 УЕ 204623.

armored

Признак бронированного автомобиля.

Варианты значения:

  • да;
  • нет.

unique_id

Уникальный идентификатор объявления.

Элемент используется, если не указан VIN номер.

Произвольный набор цифр, букв, знаков - и _ до 50 символов.

action

Статус продажи.

Элемент позволяет снять объявление с продажи или опубликовать повторно.

Возможные значения:

  • hide — деактивировать объявление;
  • show — возобновить показ.

exchange

Обмен.

Возможные значения:

  • Нет;
  • Рассмотрю варианты.

panoramas_autoru

Панорама экстерьера автомобиля.

  • Используйте видео 360°, снятое с помощью специального стенда или в приложении Авто.ру.

  • Загрузите файл размером от 20 до 500 МБ.

  • По ссылке видео должно скачиваться.

  • Можно использовать короткие ссылки на Я.Диск.

  • Ссылку нужно указать в теге <url> внутри panoramas_autoru.

    <panoramas_autoru>
             <url>ссылка на видео-файл</url>
        </panoramas_autoru>

panoramas

Панорама салона автомобиля.

  • Используйте фотографию 360°, её можно снять на специальную экшн-камеру.
  • Загрузите файл размером от 20 до 500 МБ.
  • По ссылке снимок должен скачиваться.
  • Можно использовать короткие ссылки на Я.Диск.
  • Ссылку нужно указать в теге <url> внутри <interior_urls>.
  • К объявлению можно добавить только одну панораму салона.
<panoramas>
          <interior_urls>
            <url>https://yadi.sk/i/dsLjgIveI8HTSA</url>
          </interior_urls>
        </panoramas>

tech_param_id

Код модификации из каталога Авто.ру.

engine_volume

Объем двигателя в см³.

Нельзя передавать одновременно с modification_id.

engine_power

Мощность двигателя с указанием единиц измерения л.с. либо кВт.

Нельзя передавать одновременно с modification_id.

engine_type

Тип двигателя:

  • Бензин;
  • Дизель;
  • Гибрид;
  • Электро;
  • ГБО;
  • Водородный.

Нельзя передавать одновременно с modification_id.

gearbox

Коробка передач:

  • Автоматическая;
  • Механическая;
  • Автомат вариатор;
  • Автомат робот.

Нельзя передавать одновременно с modification_id.

drive

Привод:

  • Задний;
  • Передний;
  • Полный.

Нельзя передавать одновременно с modification_id.

nameplate

Значение из каталога Авто.ру.

delivery_info

Адрес доставки.

Можно передать до 10 адресов.

<delivery_info>
          <delivery>
            <address>Москва, Льва Толстого 16</address>
          </delivery>
          <delivery>
            <address>Санкт-Петербург, Невский проспект 1</address>
          </delivery>
        </delivery_info>

Чтобы удалить адреса, передайте пустой элемент delivery_info.

Если передать фид без delivery_info, прошлые адреса останутся в объявлении.

accepted_autoru_exclusive

Укажите элемент, если вы не размещаете объявления о продаже этого авто на других сайтах. В публикации может появиться значок «Только на «Авто.ру».

Примечание

Признак «Только на Авто.ру» может быть отозван в случае выявления размещения объявления о продаже этого авто на других сайтах.

Значения:

  • true — включен,
  • false — выключен.
<accepted_autoru_exclusive>true</accepted_autoru_exclusive>

online_view_available

В объявлении появится значок «Онлайн-показы по видеосвязи».

Возможные значения:

  • true — включить значок;
  • false — отключить значок.
<online_view_available>true</online_view_available>

Если в фиде нет тега, а на форме подачи вручную проставлена галочка «Готов показать онлайн», значок останется активен.

with_nds

В объявлении появится информация о том, что цена указана с НДС.

Возможные значения:

  • true — включить;
  • false — отключить.
<with_nds>true</with_nds>

Удаление тега из фида не отключит блок. Нужно обязательно передавать значение false.

pledge_number

Номер залога автомобиля.

Номер можно найти на сайте ФНП.

Пример:

<pledge_number>2019-334-231232-123</pledge_number>

not_registered_in_russia

Автомобиль не стоит на учёте в РФ.

Возможные значения:

  • true — автомобиль не стоит на учете.
  • false — стоит на учете.
    Можно не указывать.
