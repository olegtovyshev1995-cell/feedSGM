Размещение объявлений с помощью фидов

  • Загрузка фида
  • Результаты обработки фида
  • Правила обновления объявлений
  • Требования к прайс-листу

Фид — это файл с информацией о товарах, с помощью которого можно загрузить на сайт неограниченное количество объявлений.

Загрузка фидаЗагрузка фида

Ручная загрузка фида подразумевает, что вы один раз составляете его и добавляете на Авто.ру. Чтобы изменить объявления, нужно будет отредактировать фид и загрузить заново.

Для автоматической загрузки, нужно сначала разместить фид на своем сайте или сервере, а потом загрузить эту ссылку на Авто.ру. Если в файле были изменения, то фид обновится через час. Если изменений не было, то время обновления составит 6 часов.

Внимание

Нельзя одновременно использовать два типа загрузки для одной категории ТС. Например: если вы добавили фид в категории Легковые с пробегом с типом загрузки Автоматический, то загрузить еще один в этой же категории, но вручную, не получится.

Как загрузить фид?

Вручную
Автоматически

  1. Составьте фид в формате XML по техническим требованиям для

    • легковых автомобилей;
    • коммерческого транспорта.

  2. Перейдите в личный кабинет.

  3. В левой боковой панели нажмите Фиды.

  4. В разделе Настройка фидов:

    • укажите категорию автомобиля;
    • укажите типа загрузки → Ручная;
    • нажмите ссылку Выбрать XML-файл и прикрепите фид;
    • выберите пункт Удалять объявления, если хотите удалять загруженные ранее объявления, которых нет в новом фиде;
    • выберите пункт Не удалять загруженные вручную фотографии, если хотите оставить фотографии, которые вы добавляли к объявлениям вручную из личного кабинета;
    • выберите пункт Не удалять услуги для объявлений, если хотите оставить услуги; которые вы активировали с помощью предыдущих фидов или вручную из личного кабинета.

  5. Нажмите кнопку Добавить фид.

  1. Составьте фид в формате XML по техническим требованиям для

    • легковых автомобилей;
    • коммерческого транспорта.

  2. Перейдите в личный кабинет.

  3. В левой боковой панели нажмите Фиды.

  4. В разделе Настройка фидов:

    • укажите категорию автомобиля;

    • укажите тип загрузки → Автоматическая:

    • в поле URL фида укажите ссылку на скачивание файла. Фид должен быть размещен на сайте или сервере. Ссылки на файлообменники и облачные хранилища не принимаются. Если фид можно скачать только с помощью логина и пароля, добавьте их в ссылку для скачивания. Пример: http://login:password@www.site.ru/price_list_cars.xml;

    • выберите пункт Удалять объявления, если хотите удалять загруженные ранее объявления, которых нет в новом фиде;

    • выберите пункт Не удалять загруженные вручную фотографии, если хотите оставить фотографии, которые вы добавляли к объявлениям вручную из личного кабинета;

    • выберите пункт Не удалять услуги для объявлений, если хотите оставить услуги, которые вы активировали с помощью предыдущих фидов или вручную из личного кабинета.

  5. Нажмите кнопку Добавить фид.

Время обработки прайс-листа зависит от размера файла и загруженности сайта.

Результаты обработки фидаРезультаты обработки фида

Чтобы узнать результаты обработки фида:

  1. Перейдите в личный кабинет.

  2. В левой боковой панели нажмите Фиды.

  3. Перейдите в раздел История загрузок.

    Возможные статусы фида:

    • В очереди – обработка скоро начнется;
    • Обрабатывается — обработка в процессе, это занимает не больше получаса;
    • Обработан — фид успешно загружен на сайт;
    • Ошибка обработки — не удалось загрузить фид. Проверьте корректность ссылки или файла.

    Чтобы посмотреть, в каких объявлениях нашлись ошибки и предупреждения, нажмите на название фида. Список будет в самом низу страницы.

Правила обновления объявленийПравила обновления объявлений

Активные и снятые с публикации

При изменении данных в фиде (вручную или автоматически), объявление обновится, если совпадут поля:

  • mark;
  • model;
  • tech_param_id (только для легковых);
  • year;
  • color;
  • VIN или uniq_id (заданный пользователем идентификатор. Используется, если не указан VIN).

Примечание

Если хотя быть одно из этих полей в новой версии фида не совпадет с предыдущей — создастся новое объявление.

Удаленные и заблокированные

Если вы удалили публикацию через автозагрузку, восстановить ее можно в течение 30 суток в категориях С пробегом и Новые. После этого срока объявление размещается как новое.

Внимание

Заблокированные модерацией объявления нельзя восстановить или создать заново.
